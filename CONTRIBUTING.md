# Contributing

Thanks for contributing to ScreenText!

1. Open an issue for a bug or feature proposal.
2. Keep pull requests focused and add tests where practical.
3. Run `python -m pytest -q`.
4. For OCR bugs, include Tesseract version, language data, Windows display scaling, and a non-sensitive reproducible sample when possible.
5. Never commit screenshots containing private information or credentials.

Contributions are distributed under this repository's MIT license.
